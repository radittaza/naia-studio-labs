FAQ

Yang sering ditanyakan.

Apa bedanya sekali bayar dan paket maintenance? +

Sekali bayar: website diserahkan penuh setelah selesai, dengan masa garansi perbaikan bug. Paket maintenance: biaya awal lebih ringan, lalu ada biaya bulanan untuk backup, perbaikan, update konten, dan pemantauan agar website tetap berjalan.

Berapa lama pengerjaannya? +

Tergantung skala. Landing page biasanya sekitar 1–2 minggu, aplikasi CRUD 3–6 minggu, dan SaaS atau sistem custom dibahas per tahap setelah kebutuhan jelas.

Apakah saya mendapatkan source code-nya? +

Ya. Setelah pelunasan, source code dan akses ke website diserahkan ke kamu.

Bagaimana sistem pembayarannya? +

Umumnya DP di awal, lalu pelunasan setelah website selesai dan kamu setujui. Detailnya disepakati saat diskusi.

Kalau saya sudah punya website, bisa ambil maintenance saja? +

Bisa — hubungi kami dulu supaya kami bisa cek teknologi dan kondisi website-nya.
